# Goal
Estimate the daily effective reproduction number, Rt, across the entire observation window using observed case counts and a renewal-equation-based model.

# Observation window and data source
- Span: 150 consecutive days, from 2023-01-01 through 2023-05-30.
- Input file: data/cases.csv
  - Columns: date (YYYY-MM-DD), cases (integer counts).

# Fixed epidemiological inputs
Treat the following as known, with no uncertainty propagation:
- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (infection to observed case): Log-normal distribution with mean 5 days and standard deviation 2 days.

# Characteristics to represent in the observation process
- A nonzero delay from infection to reporting, governed by the above log-normal distribution.
- A weekly pattern arising from reduced reporting on weekends.
- Time-varying case ascertainment; the path over time is unknown and must be inferred from the data.
- Observation noise that is overdispersed relative to a homogeneous Poisson process.

# Modeling requirements
- Base the model on the renewal equation.
- Link latent infections to observed cases via the reporting delay distribution.
- Explicitly include:
  - day-of-week effects,
  - a time-varying ascertainment component, and
  - overdispersed observation noise (e.g., negative binomial).

# Implementation constraints
- Use the EpiAware.jl package in Julia.
- Build the model using EpiAware’s primitives.
- Refer to epiaware_docs.md for the API (types and functions).

# Output
Produce daily point estimates of Rt for the full period and write them to outputs/rt_estimates.csv with columns:
- date (YYYY-MM-DD)
- Rt_median (point estimate)
- Rt_lower (5th-percentile bound; optional but encouraged)
- Rt_upper (95th-percentile bound; optional but encouraged)

# Robustness
- If the code throws errors, identify the cause and correct them.
- If the resulting estimates appear implausible, revise the model accordingly and re-run.
