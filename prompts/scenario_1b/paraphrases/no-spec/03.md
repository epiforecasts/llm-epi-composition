# Goal
Compute daily estimates of the effective reproduction number R_t (the expected number of secondary infections generated by an individual infected at time t) from observed outbreak data.

# Time frame and inputs
- Observation window: 150 days spanning 2023-01-01 through 2023-05-30.
- Source file: data/cases.csv
  - Columns:
    - date (YYYY-MM-DD)
    - cases (integer counts)

# Fixed epidemiological quantities
Treat the following as known, with no uncertainty propagation (they originate from external studies of the pathogen):
- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (infection to observed case): log-normal distribution with mean 5 days and standard deviation 2 days.

# Characteristics of the observations
- Case reports are delayed relative to infection times according to the reporting delay above.
- Counts are integers and show day-of-week variation consistent with lower reporting on weekends.
- Variability exceeds what a homogeneous Poisson model would imply.

# Modeling requirement
- Build the model around the renewal equation. Use it to relate R_t, the generation interval, and past infections to form the latent infection process, and then map latent infections to reported cases via the specified reporting delay.

# Output specification
- Produce point estimates of R_t for every day in the observation period.
- Write results to outputs/rt_estimates.csv with these columns:
  - date (YYYY-MM-DD)
  - Rt_median (point estimate)
  - Rt_lower (5th-percentile credible/confidence bound, optional but encouraged)
  - Rt_upper (95th-percentile credible/confidence bound, optional but encouraged)

# Implementation notes
- Any programming language or framework may be used.
- If your code encounters errors, identify the cause and correct them.
- If the output appears implausible, revise the model and run it again.
