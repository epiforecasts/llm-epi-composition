# Time-varying reproduction number estimation

You will estimate the time-varying effective reproduction number $R_t$ (the mean count of secondary infections generated by a person infected at time $t$) using daily infectious disease outbreak counts.

## Input data

Daily case data span 150 days from 2023-01-01 through 2023-05-30. The file is located at:

- `data/cases.csv` containing columns `date` (YYYY-MM-DD format) and `cases` (integer values).

## Fixed epidemiological parameters

The following distributions are derived from external pathogen studies. Use them as fixed constants without uncertainty propagation.

- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (from infection to case observation): log-normal distribution with mean 5 days and standard deviation 2 days.

## Data characteristics

- A reporting delay exists between infection and case observation, following the distribution specified above.
- Day-of-week effects are present in the counts, reflecting lower weekend reporting.
- Counts are integers.
- Observation noise exceeds what a homogeneous Poisson model would predict.

## Requirements

Generate daily point estimates of $R_t$ covering the entire observation period.

**Your model must be based on the renewal equation.** Specifically, model the infection process using the relationship among $R_t$, the generation interval, and historical infections, then link the latent infection process to observed cases through the reporting delay.

Any language or framework is permitted.

Write your final $R_t$ estimates to `outputs/rt_estimates.csv` with these columns:

- `date` (YYYY-MM-DD format)
- `Rt_median` (point estimate)
- `Rt_lower` (5th-percentile credible/confidence bound, optional but encouraged)
- `Rt_upper` (95th-percentile credible/confidence bound, optional but encouraged)

Diagnose and fix any errors your code produces. If results appear implausible, modify the model and execute again.
