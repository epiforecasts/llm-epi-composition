# Goal
Estimate the daily effective reproduction number, Rt (the mean number of secondary infections generated by an individual infected at time t), from observed outbreak data.

# Inputs
- Time span: 150 days covering 2023-01-01 through 2023-05-30.
- Source file: data/cases.csv
  - Columns:
    - date (formatted as YYYY-MM-DD)
    - cases (integer counts)

# Fixed epidemiological quantities
Use these as known without propagating uncertainty:
- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay from infection to case observation: log-normal distribution with mean 5 days and standard deviation 2 days.

# Characteristics of the observations
- A delay exists between infection and when a case is recorded; use the reporting delay distribution above.
- Daily counts are integers and show day-of-week patterns consistent with lower weekend reporting.
- Variability exceeds what a homogeneous Poisson model would imply.

# Modeling requirements
- Produce daily point estimates of Rt for the entire observation window.
- Base the infection process on the renewal equation, linking Rt and the generation interval to past infections.
- Map the latent infection process to observed cases using the reporting delay distribution.
- Implementation must use the EpiAware.jl Julia package, composing the model from EpiAware’s primitives.
- Refer to epiaware_docs.md for the EpiAware API (available types and functions).

# Output
Write the final Rt estimates to outputs/rt_estimates.csv with these columns:
- date (YYYY-MM-DD)
- Rt_median (point estimate)
- Rt_lower (5th-percentile credible/confidence bound, optional but encouraged)
- Rt_upper (95th-percentile credible/confidence bound, optional but encouraged)

# Error handling and validation
- If the code produces errors, identify the cause and correct them.
- If the resulting estimates appear implausible, revise the model and run it again.
