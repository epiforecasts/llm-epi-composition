# Time-Varying Reproduction Number Estimation

This assignment involves determining the time-varying effective reproduction number ($R_t$), which represents the average number of secondary infections generated by an individual infected at time $t$. This estimation will be performed using observed daily infection counts from an ongoing infectious disease outbreak.

## Input Data

Observations span 150 days, from January 1, 2023, through May 30, 2023. The necessary data is located in `data/cases.csv`, containing two columns: `date` (formatted as YYYY-MM-DD) and `cases` (representing integer counts).

## Pathogen Characteristics

The following epidemiological parameters, derived from external pathogen studies, should be considered fixed and certain; no uncertainty propagation is required for them:

-   The generation interval follows a Gamma distribution with a mean of 5.5 days and a standard deviation of 2 days.
-   The reporting delay, defined as the time from infection to case observation, is described by a log-normal distribution with a mean of 5 days and a standard deviation of 2 days.

## Observed Data Characteristics

Several structural features are present in the observation data:

-   A reporting delay exists between the actual infection event and its observation as a reported case, with its distribution specified previously.
-   The reported counts are integer values and display day-of-week variations, indicating patterns such as decreased reporting on weekends.
-   The level of observation noise exceeds what a homogeneous Poisson model would predict.

## Estimation Procedure

The objective is to compute daily point estimates for $R_t$ across the entire 150-day observation window.

Your model must be fundamentally built upon the renewal equation. This involves leveraging the interrelationship between $R_t$, the generation interval, and previous infections to simulate the infection dynamics. Subsequently, link this latent infection process to the observed case data through the specified reporting delay.

Implementation is required using the `EpiAware.jl` Julia package. Construct the model by utilizing the primitives provided by EpiAware. Refer to the `epiaware_docs.md` file for details on available types and functions within the EpiAware API.

## Output Specifications

The final $R_t$ estimates should be saved to the file `outputs/rt_estimates.csv`. This CSV file must contain the following columns:

-   `date` (in YYYY-MM-DD format)
-   `Rt_median` (representing the point estimate)
-   `Rt_lower` (an optional, but recommended, 5th-percentile credible or confidence bound)
-   `Rt_upper` (an optional, but recommended, 95th-percentile credible or confidence bound)

## Error Management and Refinement

Should any errors arise during execution, they must be diagnosed and resolved. In cases where the computed results appear implausible, the model should be adjusted and re-executed.
