# Objective
Estimate the time-varying effective reproduction number, R_t (the mean number of secondary infections generated by someone infected at time t), from daily outbreak counts.

# Available data
- Observation window: 150 consecutive days spanning 2023-01-01 through 2023-05-30.
- Input file: data/cases.csv containing:
  - date (YYYY-MM-DD)
  - cases (integer counts)

# Fixed epidemiological quantities
Treat these as known and fixed; do not model or propagate uncertainty in them.
- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay from infection to case observation: log-normal distribution with mean 5 days and standard deviation 2 days.

# Characteristics of the observations
- A nonzero delay exists between infection events and reported cases, following the reporting-delay distribution above.
- The counts are integers and show day-of-week variation, including lower reporting on weekends.
- The variability in observations exceeds what a homogeneous Poisson process would imply.

# Modelling requirements
- Base the analysis on the renewal equation: link R_t and the generation interval to generate the latent infection process, and map latent infections to observed cases via the reporting delay.
- Produce daily point estimates of R_t across the entire observation period.

# Environment and tools
- Use Julia.
- Standard Julia packages are available.
- For any probabilistic or Bayesian components, use Turing.jl. A Turing.jl API reference is provided in turing_api_docs.md.

# Output specification
Write the final R_t estimates to outputs/rt_estimates.csv with these columns:
- date (YYYY-MM-DD)
- Rt_median (point estimate)
- Rt_lower (5th percentile; optional but encouraged)
- Rt_upper (95th percentile; optional but encouraged)

# Error handling and plausibility checks
If the code throws errors, identify the cause and correct them. If the resulting estimates appear implausible, revise the model and run the analysis again.
