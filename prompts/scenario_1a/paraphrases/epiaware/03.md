# Estimation of Time-Varying Reproduction Number

The objective is to determine the time-varying effective reproduction number, $R_t$, which represents the average count of secondary infections originating from an individual infected at time $t$. This estimation will be based on daily case counts from an ongoing infectious disease outbreak.

## Input Data

The observation window spans 150 days, specifically from 2023-01-01 through 2023-05-30. The relevant data is located in the file `data/cases.csv`, structured with two columns:
*   `date`: Formatted as YYYY-MM-DD.
*   `cases`: Integer values representing daily counts.

## Pathogen-Specific Parameters

The following parameters, derived from external pathogen studies, should be treated as fixed and known, with no requirement to account for their inherent uncertainty:

*   **Generation Interval**: This interval follows a Gamma distribution, characterized by a mean of 5.5 days and a standard deviation of 2 days.
*   **Reporting Delay**: The time from infection to observation in reported cases adheres to a log-normal distribution, with a mean of 5 days and a standard deviation of 2 days.

## Inherent Data Characteristics

The observed data exhibits several key structural attributes:

*   A reporting delay exists between the actual time of infection and the observation of a case, as specified by the distribution above.
*   Case counts are inherently integer values.
*   The data displays fluctuations according to the day of the week, consistent with reduced reporting activity on weekends.
*   The level of observation noise exceeds what would be anticipated from a simple homogeneous Poisson model.

## Task Requirements

Your assignment is to generate daily point estimates for $R_t$ covering the entire 150-day observation period.

**Implementation Framework:**
The solution must be developed using the `EpiAware.jl` Julia package. Models should be constructed by utilizing the primitive components provided within EpiAware's API. The `epiaware_docs.md` file serves as the reference for available types and functions within the EpiAware API.

**Output Specification:**
The final $R_t$ estimates should be stored in `outputs/rt_estimates.csv`. This file must include the following columns:

*   `date`: In YYYY-MM-DD format.
*   `Rt_median`: The calculated point estimate.
*   `Rt_lower`: An optional, but recommended, 5th-percentile credible or confidence bound.
*   `Rt_upper`: An optional, but recommended, 95th-percentile credible or confidence bound.

**Quality Assurance:**
Any errors encountered during code execution must be diagnosed and resolved. Should the generated results appear implausible, the underlying model should be adjusted and re-executed.
