# Goal
Estimate the time-varying effective reproduction number R_t (the average number of secondary infections caused by an individual infected at time t) from observed daily counts.

# Study window and input data
- Observation span: 150 consecutive days, from 2023-01-01 through 2023-05-30.
- Source file: data/cases.csv
  - Columns:
    - date (YYYY-MM-DD)
    - cases (integer counts)

# Known epidemiological distributions
Treat all parameters below as fixed inputs; do not propagate uncertainty.
- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (infection to case observation): log-normal distribution with mean 5 days and standard deviation 2 days.

# Characteristics of the observations
- Reports are delayed relative to infection times as described by the reporting-delay distribution above.
- Counts are integers and show a day-of-week pattern consistent with reduced weekend reporting.
- Variability exceeds what would be anticipated under a homogeneous Poisson model.

# Requirements
- Produce daily point estimates of R_t for the entire observation window.

# Implementation constraints
- Use the EpiAware.jl Julia package.
- Build the model using EpiAware’s primitives.
- The EpiAware API reference is provided in epiaware_docs.md; consult it for available types and functions.

# Output
Write the final R_t estimates to outputs/rt_estimates.csv with the following columns:
- date (YYYY-MM-DD)
- Rt_median (point estimate)
- Rt_lower (5th-percentile credible/confidence bound, optional but encouraged)
- Rt_upper (95th-percentile credible/confidence bound, optional but encouraged)

# Error handling and model adequacy
- If the code produces errors, diagnose and correct them.
- If the estimates appear implausible, revise the model and run it again.
