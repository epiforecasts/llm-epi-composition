# Time-varying reproduction number estimation

You will analyze daily infectious disease outbreak counts to estimate the time-varying effective reproduction number $R_t$, defined as the mean number of secondary infections generated by an individual infected at time $t$.

## Input data

Daily observations span 150 days from 2023-01-01 through 2023-05-30. Data location:

- `data/cases.csv` containing columns `date` (YYYY-MM-DD format) and `cases` (integer count values).

## Fixed epidemiological parameters

The following distributional assumptions are derived from external pathogen studies and should be treated as known constants without uncertainty propagation:

- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (time from infection to case observation): log-normal distribution with mean 5 days and standard deviation 2 days.

## Data characteristics

- Case observations are delayed relative to infection times according to the reporting delay distribution specified above.
- Integer-valued counts display day-of-week effects reflecting weekend reporting reductions.
- Observation noise exceeds what a homogeneous Poisson model would predict.

## Requirements

Generate daily $R_t$ point estimates covering the entire observation period.

**Framework constraint: Use the EpiAware.jl Julia package.** Build the model using EpiAware primitives. The file `epiaware_docs.md` contains the EpiAware API reference documenting available types and functions.

Write final $R_t$ estimates to `outputs/rt_estimates.csv` with the following columns:

- `date` (YYYY-MM-DD format)
- `Rt_median` (point estimate value)
- `Rt_lower` (5th-percentile credible/confidence bound, optional but encouraged)
- `Rt_upper` (95th-percentile credible/confidence bound, optional but encouraged)

Handle any errors by diagnosing and correcting them. If output appears implausible, modify the model and execute again.
