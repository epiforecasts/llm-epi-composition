# Time-varying reproduction number estimation

You will estimate the time-varying effective reproduction number $R_t$ (the mean count of secondary infections generated by one person infected at time $t$) using daily infectious disease outbreak counts.

## Input data

Daily observations span 150 days from 2023-01-01 through 2023-05-30. The dataset is located at:

- `data/cases.csv` containing columns `date` (YYYY-MM-DD format) and `cases` (integer values).

## Fixed epidemiological parameters

The following distributions are derived from independent pathogen studies. Use them as known constants without uncertainty propagation.

- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (time from infection to case observation): log-normal distribution with mean 5 days and standard deviation 2 days.

## Data characteristics

- Case observations are delayed relative to infection times according to the reporting delay distribution specified above.
- Day-of-week effects are present in the counts, reflecting diminished weekend reporting.
- Counts are integers and display observation noise exceeding that predicted by a homogeneous Poisson model.

## Requirements

Generate daily $R_t$ point estimates covering the entire observation period.

**Implementation language: Julia.** You may use standard Julia packages. Reference documentation for the Turing.jl API is available in `turing_api_docs.md`; apply Turing.jl for probabilistic or Bayesian modelling tasks.

Write the final $R_t$ estimates to `outputs/rt_estimates.csv` with these columns:

- `date` (YYYY-MM-DD format)
- `Rt_median` (point estimate)
- `Rt_lower` (5th-percentile credible/confidence bound, optional but encouraged)
- `Rt_upper` (95th-percentile credible/confidence bound, optional but encouraged)

Diagnose and resolve any errors that occur during execution. If outputs appear implausible, modify the model and execute again.
