# Daily Estimation of the Effective Reproduction Number ($R_t$)

The core objective of this assignment is to compute the time-varying effective reproduction number ($R_t$), defined as the average number of secondary infections produced by an individual infected at time $t$. This estimation will be conducted using observed daily case counts from an infectious disease outbreak.

## Input Data Specification

Case count data spans a 150-day observation window, commencing on January 1, 2023, and concluding on May 30, 2023. This information is located in the file `data/cases.csv`. The file is structured with two columns: `date` (formatted as YYYY-MM-DD) and `cases` (representing integer counts).

## Pathogen-Specific Parameters

Several epidemiological parameters, derived from external studies of the pathogen, are to be treated as fixed and known values without propagating their inherent uncertainty. These include:

*   **Generation Interval**: This follows a Gamma distribution with a mean of 5.5 days and a standard deviation of 2 days.
*   **Reporting Delay**: The duration from infection to observed case is described by a log-normal distribution, possessing a mean of 5 days and a standard deviation of 2 days.

## Inherent Data Characteristics

The provided case data exhibits specific structural attributes:

*   A reporting delay exists between the actual infection event and its observation as a reported case, with its distribution detailed above.
*   Case counts are strictly integer-valued.
*   Day-of-week fluctuations are present, consistent with diminished reporting activity during weekends.
*   The observed noise level in the data is greater than would be anticipated from a homogeneous Poisson model.

## Implementation and Output Requirements

The solution must generate daily point estimates for $R_t$ covering the entire 150-day observation period.

The implementation must be in Julia, leveraging standard Julia packages. For any probabilistic or Bayesian modeling components, utilize Turing.jl; an API reference for Turing.jl is accessible at `turing_api_docs.md`.

The final $R_t$ estimates are to be saved to `outputs/rt_estimates.csv`. This output file should include the following columns:

*   `date`: The date in YYYY-MM-DD format.
*   `Rt_median`: The central point estimate for $R_t$.
*   `Rt_lower`: The 5th percentile of the credible or confidence interval for $R_t$.
*   `Rt_upper`: The 95th percentile of the credible or confidence interval for $R_t$.

It is important to note that the primary evaluation metrics for this study include coverage and interval width, in addition to the root mean square error (RMSE) of point estimates. If the chosen estimation methodology does not inherently provide uncertainty quantification (e.g., a basic ratio estimator), the `Rt_lower` and `Rt_upper` columns may be omitted. Submissions without these bounds will only be assessed on RMSE and will not be considered in coverage or width analyses.

Robustness is expected: any errors encountered during execution must be diagnosed and resolved. Furthermore, if the generated results appear implausible, the underlying model should be adjusted and the estimation process rerun.
