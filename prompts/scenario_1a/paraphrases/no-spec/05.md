# Time-varying reproduction number estimation

Your objective is to estimate the effective reproduction number $R_t$ as it varies over time (representing the mean count of secondary infections generated by a person infected at time $t$) using observed outbreak data for an infectious disease.

## Input data

Daily case counts span 150 days from 2023-01-01 through 2023-05-30. The file location is:

- `data/cases.csv` containing columns `date` (format YYYY-MM-DD) and `cases` (integer values).

## Fixed epidemiological parameters

The following parameter distributions are derived from external pathogen studies. Consider them known and fixed; uncertainty propagation is not required.

- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (time from infection to case observation): log-normal distribution with mean 5 days and standard deviation 2 days.

## Data characteristics

- Case observation lags behind infection by a delay period described by the distribution specified above.
- Case counts are integers and display day-of-week effects reflecting diminished weekend reporting.
- Observation noise exceeds what a homogeneous Poisson model would predict.

## Requirements

Generate point estimates of $R_t$ for each day across the entire observation period.

Any method, language, or framework is permitted.

Write the resulting $R_t$ estimates to `outputs/rt_estimates.csv` with these columns:

- `date` (format YYYY-MM-DD)
- `Rt_median` (point estimate)
- `Rt_lower` (5th-percentile credible/confidence bound, optional but encouraged)
- `Rt_upper` (95th-percentile credible/confidence bound, optional but encouraged)

Should your code produce errors, identify and resolve them. Should results appear implausible, modify the model and execute again.
