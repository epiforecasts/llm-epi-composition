# Time-varying reproduction number estimation

You will estimate the time-varying effective reproduction number $R_t$, defined as the mean number of secondary infections generated by a person infected at time $t$, using daily infectious disease outbreak counts.

## Input data

Daily observations span 150 days from 2023-01-01 through 2023-05-30. The input file is:

- `data/cases.csv` containing columns `date` (YYYY-MM-DD format) and `cases` (integer).

## Fixed epidemiological parameters

The following distributions are derived from external pathogen studies and should be treated as known constants without uncertainty propagation.

- Generation interval: Gamma distribution with mean 5.5 days and standard deviation 2 days.
- Reporting delay (from infection to case observation): log-normal distribution with mean 5 days and standard deviation 2 days.

## Data characteristics

- Case observations are delayed relative to infection times according to the reporting delay distribution specified above.
- Integer-valued counts display day-of-week effects reflecting lower weekend reporting.
- Observation noise exceeds what a homogeneous Poisson model would predict.

## Requirements

Generate daily $R_t$ point estimates covering the entire observation period.

Any language, framework, or methodology is permitted.

Write your final estimates to `outputs/rt_estimates.csv` with the following columns:

- `date` (YYYY-MM-DD format)
- `Rt_median` (point estimate)
- `Rt_lower` (5th-percentile credible/confidence bound)
- `Rt_upper` (95th-percentile credible/confidence bound)

Primary evaluation metrics include coverage, interval width, and point-estimate RMSE. Methods that do not yield uncertainty quantification (e.g. naive ratio estimators) may exclude `Rt_lower` and `Rt_upper`; such submissions will be evaluated only on RMSE and excluded from coverage and width metrics.

Diagnose and resolve any errors in your code. If outputs appear implausible, modify the model and re-execute.
